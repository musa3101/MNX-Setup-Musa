# Hero Video Production Skill

Esta skill define las mejores prácticas para crear vídeos destinados a secciones principales (**Hero Sections**) de sitios web modernos.

## 1. Principios de un Vídeo Hero Efectivo

1. **Ritmo y Duración:**
   - La duración ideal total para una cabecera web oscila entre **15 y 30 segundos** en total (o micro-vídeos de ritmo rápido).
   - Con 10 a 15 clips de entrada, cada toma debe mantenerse entre **1.5 y 2.5 segundos** para mantener la atención sin saturar.
   - Variar entre planos generales, planos detalle y movimiento dinámico de cámara.

2. **Transiciones Estilizadas:**
   - Para un look cinematográfico y premium: **Cross Dissolve** suave (10 a 18 frames) o cortes secos al ritmo visual (*hard cut on action*).
   - Para webs dinámicas / tech: transiciones rápidas de whip pan o zoom sutil.
   - Evitar transiciones llamativas de los años 90 (cortinillas de estrella, espirales).

3. **Seamless Loop (Bucle Infinito):**
   - El último clip debe enlazar naturalmente con el primero.
   - Técnica recomendada: Aplicar una disolución cruzada (*cross dissolve*) entre el final del último clip y el inicio del primer clip para que al reproducirse en `loop` continuo en la web no se note el salto.

4. **Legibilidad del Texto Web y Contraste:**
   - Recordar que sobre el vídeo hero suelen colocarse títulos `<h1>`, subtítulos y botones CTA.
   - Aplicar una ligera curva de contraste o viñeteado en FilmCraft para asegurar que los textos blancos destaquen, o dejar espacio visual despejado.

5. **Optimización Web y Formato:**
   - Relación de aspecto: 16:9 panorámico (1920x1080) a 30fps o 60fps.
   - Códec: H.264 / MP4 con perfil web (sin pista de audio si la web reproduce en silencio con `muted autoplay loop playsinline`).
   - Bitrate moderado para tiempos de carga ultrarrápidos (LCP optimizado).
