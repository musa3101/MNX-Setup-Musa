# Playwright CLI - Visual Testing & Browser Automation

Esta skill le proporciona al asistente "ojos y manos" en un navegador Chrome real para auditar y probar aplicaciones web locales o remotas.

## Cuándo usar Playwright CLI
- **Auditoría Visual**: Comprobar el diseño renderizado real de la web (`localhost:3000` / `localhost:5173`), sacando screenshots de escritorio y móvil para verificar que no haya elementos rotos o textos montados.
- **Testing Interactivo**: Rellenar formularios, hacer click en botones, abrir modales y comprobar flujos de autenticación o compras.
- **Consola de Errores**: Capturar errores de JavaScript en tiempo de ejecución o fallos de red (404, 500) que no se ven en el código estático.

## Capacidades
- Ejecución de pruebas y scripts con Playwright y Chrome en modo headless o con interfaz.
- Generación de capturas de pantalla para inspección de diseño con skills como `/taste-skill-v2` o `/impeccable`.
