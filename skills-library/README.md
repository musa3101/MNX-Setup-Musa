## 🔄 Sincronización

Para comparar las skills de este repositorio con las de tu IDE local:

```bash
bash skills-library/sync-skills.sh
```

- Copiar una skill del IDE al repositorio: `bash skills-library/sync-skills.sh --to-repo NOMBRE_SKILL`
- Copiar una skill del repositorio al IDE: `bash skills-library/sync-skills.sh --to-ide NOMBRE_SKILL`
