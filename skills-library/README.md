# 🧠 Arsenal de Skills — MYNEXT Setup 2.0

Colección de habilidades curadas para **Google Antigravity IDE** y el ecosistema de desarrollo de **MYNEXT**, orientadas al diseño de lujo, arquitectura limpia y máxima velocidad de desarrollo.

---

## 🎨 1. Dirección de Arte & Diseño Ultra-Premium (Anti-Slop)

| Skill | Descripción |
|---|---|
| **[`taste-skill-v2`](./taste-skill-v2/)** | Dirección de arte inspirada en 247 galerías premium (One Page Love, Awwwards). Elimina interfaces genéricas ("AI slop") mediante composición tipográfica, paletas calibradas y layouts asimétricos. |
| **[`high-end-visual-design`](./high-end-visual-design/)** | Acabado visual luxury (estilo Linear/Apple): sombras atmosféricas multicapa, tactile double-bezels, bordes finos, microespaciados y contrastes de luz. |
| **[`emil-design-eng`](./emil-design-eng/)** | Filosofía de diseño de Emil Kowalski: pulido obsesivo de UI, transiciones sutiles, microinteracciones táctiles y detalles invisibles. |
| **[`gpt-taste`](./gpt-taste/)** | Reglas de marca y combinaciones tipográficas de MYNEXT (MUSERO x ERTINAS, ELEGIST x MARLINO, etc.). |
| **[`impeccable`](./impeccable/)** | Auditoría y pulido de interfaces visuales, detección de antipatrones estéticos y control de calidad de maquetación. |
